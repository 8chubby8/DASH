no subset

Drop a module's layout and its artwork anywhere on this window.

Or use Load files…. Everything stays on this machine — the tool makes no network calls and has no server.

  • h_large_day.json and the rest — one layout per slot
  • *.svg and *.png — the artwork those layouts reference
  • svg-subset.json — required to draw vector layers. It is the authoritative definition of what DASH renders, read by the DASH parser and by this tool. Without it this tool would be showing you the browser's SVG support, which is not evidence of anything.

Whole folders can be dropped. From the DASH repo, arduino/current_sketches/ClimateWifi/assets/ plus svg-subset.json is everything you need.
